LECA website update package

Contents:
- leca-section.html: section markup to insert immediately before Publications in research.html.
- leca-section.css: responsive styling addition.
- assets/leca_conditions_figure.jpg: four-panel comparison built from the supplied real laboratory photographs.
- assets/leca_*.jpg: individually edited real photographs.
- assets/pva_leca_self_healing_mechanism.svg: mechanism diagram for coating rupture, sodium-silicate release and C-S-H formation.

Photo treatment:
The blue background was isolated, the crop tightened, and brightness/contrast/sharpness were adjusted mildly.
The aggregate texture and geometry were not fabricated or reshaped.

Scientific labeling:
The supplied photographs document dry LECA and the final sodium-silicate-impregnated, PVA-coated condition.
No separate photograph of sodium-silicate-impregnated but uncoated LECA was identified, so no intermediate image is claimed.

Method details included from the experimental manuscript:
- LECA impregnation: 40% sodium silicate solution, 3 days, ambient temperature.
- PVA solution: 5 wt%, prepared from 50 g PVA and 950 g sterilized water; stirred at 95 °C for 1 h and held for 24 h at ambient temperature.
- Coating: sprayed onto the impregnated LECA; layers dried with hot air from a hair dryer.

Integration:
1. Copy the assets folder into the website's existing assets directory (or adjust relative image paths).
2. Insert leca-section.html immediately before the Publications section in research.html.
3. Append leca-section.css to the existing stylesheet or copy its rules into style.css.
4. Publish through the existing GitHub Pages workflow.

Note: this is a ready-to-integrate update package, not a live GitHub deployment.
